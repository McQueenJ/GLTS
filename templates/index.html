Local language model
Install and start Ollama for Windows, then download a model here. Qwen2.5 7B needs approximately 5 GB of disk space; 16 GB RAM is recommended. The 3B model is lighter. The optional 14B model needs about 9 GB of disk space; 32 GB RAM is recommended for comfortable use. It may run slowly with 16 GB, especially with audio models loaded. Sana’ani translation is experimental and may misinterpret dialect expressions. Ollama manages its own GPU selection.
